Paste both into Claude Code's chat box, then restart.

/plugin marketplace add HeyCubit/effortless
/plugin install effortless@effortless

Every prompt gets the effort it needs.

Before a prompt runs, a small judge reads it. A rename gets Low, a migration plan gets XHigh. You never open the Effort menu.

Right on 95 to 100% of prompts it was never tuned on.

It tells you when the cache goes cold.

The footer counts down how long the prompt cache stays warm. When it runs out, one click compacts the chat, so the next message does not pay to write it all again.

Yellow from 20 minutes, red from 5.

And when the chat gets heavy.

Past 150k tokens every message re-reads the whole chat. The ring shows how full it is, with Compact or Handoff one key away.

Press C to compact or H to hand off.

It eases off before you hit the limit.

When a 5 hour or weekly limit passes 80%, Save mode keeps effort at Medium or lower until it resets.

One click. It turns itself off at the reset.

A fresh chat, nothing lost.

⇥ in the footer writes a handoff note in seconds, clears the chat and carries on from the note.

Or keep the chat and copy the note, or move to a new chat.

Set up in one click.

The first time, a band asks who should judge your prompts. Haiku needs no key and runs on your own Claude login.

Jev is about 4× faster with a TypeSafe key. Any OpenAI-compatible API works too.

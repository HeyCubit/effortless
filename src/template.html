Install

Two lines in the chat box.

No terminal. Paste both into Claude Code, restart, and a short setup asks who should judge your prompts.

› /plugin marketplace add HeyCubit/effortless
› /plugin install effortless@effortless
  1. 01PasteBoth lines, in Claude Code's chat box.
  2. 02RestartClaude Code loads the mod.
  3. 03Pick a judgeHaiku needs no key. Jev is about 4× faster with a TypeSafe key. Or bring any OpenAI-compatible API.

Does it pick right?

Right on prompts it was never tuned on.

20 held-out prompts, each labelled with the efforts a careful person would accept. A fixed effort gets about half of them.

What it saves

Honest numbers.

3×xhigh against mediumA median xhigh prompt costs about three times a medium one. Against a high default, Auto saves a lot.
76%is cache readsMost of the cost is the chat read back from cache on every tool call. Compacting before it goes cold often saves more than effort. That is what the countdown is for.
A few %against mediumIf you already run medium, the saving is small. Hard jobs still get high without you asking.
